# Forms

**Forms** est une application web bilingue de référence pour manipuler rapidement des formes simples en trois dimensions dans un contexte de dessin.

Elle fait partie d’**Eigrutel Lab — Atelier d'outils libres pour la bande dessinée**.

**Version stable : 1.0.0**  
**Date : 9 août 2026**  
**Fichier principal : `forms.html`**

## Fonction

Forms permet d’afficher et de manipuler cinq formes de base :

- boîte ;
- cylindre ;
- sphère ;
- cône ;
- pyramide.

Chaque forme peut être tournée directement à la souris ou au doigt. Des curseurs permettent également de régler précisément les rotations sur les axes X, Y et Z.

Selon la forme, l’application propose des réglages de largeur, hauteur, profondeur, diamètre, base, angle de vue et zoom. La boîte et le cylindre disposent aussi d’une option de faces semi-transparentes.

Un bouton permet de générer une pose aléatoire et un autre de réinitialiser la forme active.

## Langues

L’interface est disponible en français et en anglais. Le français est affiché par défaut. Le bouton discret `FR / EN` permet de changer de langue sans recharger la page.

## Utilisation

Aucune installation n’est nécessaire.

1. Télécharger `forms.html`.
2. Ouvrir le fichier dans un navigateur web récent.
3. Choisir une forme.
4. La faire pivoter au doigt ou à la souris, ou utiliser les curseurs X, Y et Z.
5. Ajuster ses dimensions, le zoom et, lorsque disponible, l’angle de vue.

Raccourcis : flèches = rotation ; `Maj` + flèche = pas plus important ; `R` = réinitialisation ; espace = pose aléatoire ; double-clic = réinitialisation ; molette = zoom.

# English

**Forms** is a bilingual web application for quickly manipulating simple three-dimensional forms as drawing references.

It includes a box, cylinder, sphere, cone and pyramid. Forms can be rotated directly with a mouse or touch gesture, or precisely adjusted with X, Y and Z controls.

**Stable version: 1.0.0 — 9 August 2026**

Forms is part of **Eigrutel Lab — Free Tools Workshop for Comics**, designed and developed by **Simon Léturgie** as part of **Eigrutel BD Academy**.

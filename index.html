Formes

Forms

Boîte, cylindre, sphère, cône et pyramide : les cinq formes peuvent être orientées librement et ajustées en dimensions.

Box, cylinder, sphere, cone and pyramid: all five forms can be freely oriented and adjusted in size.

Manipulation

Manipulation

Rotation au doigt ou à la souris, axes X/Y/Z, zoom, angle de vue et pose aléatoire permettent de produire rapidement une référence.

Touch or mouse rotation, X/Y/Z axes, zoom, view angle and random pose make it easy to create a quick reference.

Utilisation

Use

Aucune installation : Forms fonctionne directement dans un navigateur moderne et tient dans un fichier HTML autonome.

No installation is required: Forms runs directly in a modern browser and is contained in one self-contained HTML file.

# Changelog — Forms

## [1.0.0] — 09-08-2026

### Ajouté

- Nom public : **Forms**.
- Fichier principal : `forms.html`.
- Interface bilingue français / anglais.
- Bouton discret `FR / EN`.
- Vocabulaire :
  - Boîte / Box ;
  - Cylindre / Cylinder ;
  - Sphère / Sphere ;
  - Cône / Cone ;
  - Pyramide / Pyramid.
- Rotation au doigt ou à la souris.
- Réglages X, Y, Z.
- Réglages de dimensions selon la forme.
- Zoom et angle de vue.
- Faces semi-transparentes pour la boîte et le cylindre.
- Pose aléatoire et réinitialisation.
- Raccourcis clavier.
- Mise en page responsive.
- En-tête Eigrutel Lab et licences.
- Documentation du dépôt et page `index.html`.

### Modifié

- Nettoyage et harmonisation du HTML, CSS et JavaScript.
- Commentaires techniques bilingues français / anglais.
- Ancien titre « Volumes 3D » remplacé par **Forms**.
